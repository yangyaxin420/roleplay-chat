# 角色扮演 · 网页版

一个纯静态的沉浸式角色扮演对话页。黑白极简界面，接 DeepSeek API，数据全在本地，扔到 GitHub Pages 就能用，手机上也能开。

**线上地址：<https://yangyaxin420.github.io/roleplay-chat/>**

---

## 功能

**设定**
- 新建对话时填写：角色名、我的名字、角色设定、情境、开场白（可留空）
- 设定之后随时可以改，只影响往后的对话
- 设定窗右上角有 ✕、底部有「取消」；如果已经写了内容，关掉前会先问一句，避免手滑丢掉

**对话**
- 流式输出（一个字一个字往外蹦），可以中途点「停止」
- 支持简易 Markdown：粗体、斜体、行内代码
- Enter 发送 / Shift + Enter 换行（手机上是回车换行，点按钮发送）

**心理描写**
- 模型把内心戏写在 `【心理】…【/心理】` 里，前端内联在**每条回复的下方**，默认**收起**
- 每条回复下面都有「看心理」，点一下展开这一条，再点「收起」；互不影响
- 右上角「心理」是全部展开 / 全部收起的总开关
- 也兼容 `[心理]…[/心理]` 和 `（心理：…）` 两种写法

**回复字数**
- 右上角「字数」按钮随时切换：**短**（100~200 字）/ **中**（200~400 字）/ **长**（400~800 字）/ **自定**
- 切档同时改两处：发给模型的字数要求，和 `max_tokens` 硬上限
- 选「自定」时，用设置里那个 token 数当上限
- 切换对下一句就生效，不用重新开对话

**对话长度**
- 每段对话上限 **1000 条消息**，标题下面有实时计数（`12 / 1000 条`）
- 接近上限时计数变白提醒；到顶后输入框会锁住，提示新建一段继续

**存档**
- 左侧列表管理多段对话：点击切换、⋯ 菜单重命名 / 导出 / 删除
- 桌面端点左上角 ☰ 可以折叠侧栏，手机上是从左边滑出的抽屉
- 支持整体导入 / 导出 JSON，换设备不丢

**消息操作**
- 复制（只复制对白，不含心理描写）
- 编辑自己发过的话 → 从那里重新往下生成（会提示后面几条会被删掉）
- 删除单条消息
- 重新生成最后一条回复

**其它**
- 字号 85%–135% 可调
- 「复制完整设定」把设定 + 全部对话拼成一段纯文本，方便粘到别处接着玩
- 删除 / 清空 / 覆盖前都会二次确认

## 怎么打开

### 方式一：直接双击
双击 `index.html`，用 Chrome / Edge 打开即可。

> 某些浏览器在 `file://` 下会禁用 IndexedDB，程序会自动退回 localStorage，不影响使用。

### 方式二：本地起个服务（更稳，推荐）
```bash
node serve.js
```
然后打开 http://127.0.0.1:5173

---

## 第一次使用的三步

1. 弹出设定框，填角色名 + 角色设定（这两项必填），情境能填就填
2. 点左下角「设置」，把 DeepSeek 的 API Key（`sk-` 开头）粘进去，保存
3. 回对话框说话；如果不想先说，点「让 TA 先开口」

API Key 可以在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请。

---

## 部署到 GitHub Pages

1. 在 GitHub 建一个仓库（公开或私有都行，Pages 需要公开仓库免费版）
2. 把 `index.html`、`style.css`、`app.js` 三个文件传到仓库根目录（`serve.js` 和本文件不需要）
3. 仓库 → Settings → Pages → Source 选 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → Save
4. 等一分钟，访问 `https://你的用户名.github.io/仓库名/`

手机上把地址加到主屏幕，用起来跟 App 差不多。

---

## 关于 API Key 的安全

- Key 只存在**你自己这台设备的浏览器**里（localStorage），不会上传、不会进代码、不会进 Git
- 所以仓库里没有敏感信息，可以放心公开
- 但别在公共电脑上填；换设备需要重新填一次
- 对话数据同理，只在本机。用「导出 / 导入」迁移

## 想改的话

| 想改什么 | 改哪里 |
| --- | --- |
| 扮演规则、回复长度、心理描写格式 | 页面「设置 → 高级：系统提示词模板」，改完立即生效 |
| 配色、字号、圆角 | `style.css` 顶部的 `:root` 变量 |
| 心理描写的识别标记 | `app.js` 里的 `MARKERS` 数组 |
| 默认模型 / 温度 | `app.js` 的 `DEFAULT_SETTINGS` |

改系统提示词时留意：模板里不要删掉心理描写的格式说明，否则「心理」按钮就没有内容可显示了。

## 常见问题

**提示「API Key 无效」**
Key 复制时多了空格，或者已经被删除。重新生成一个。

**提示「对话太长了」**
到设置里把「携带上下文条数」从 24 调到 12 左右。程序只发最近 N 条给模型，更早的仍然留在存档里。

**回复很慢 / 中途断了**
`deepseek-reasoner` 本身比 `deepseek-chat` 慢很多，日常扮演建议用 chat。断了就点「重写」。

**换电脑后对话没了**
正常的，数据只存在本机。旧设备上先「导出」，新设备「导入」。
